## 搬瓦工续费的基本机制，先搞清楚这几条

搬瓦工不会自动从你的支付宝或信用卡扣款。官方明确说过：他们不存储用户的支付信息，技术上没有能力自动扣款。

但有一种"伪自动续费"的方式——提前往账户余额（Credit）里充钱，账单出来后系统会自动从余额里扣。这是目前唯一能真正省心的做法。

几条关键规则记住：

- **账单生成时间**：服务到期当天（美国时间），系统自动生成续费账单
- **宽限期**：账单生成后有 **7 天**的支付窗口，期间 VPS 照常运行
- **超期后果**：7 天内没付款，服务暂停；再拖下去就彻底终止，数据清空
- **续费价格**：和首次购买时一样，不受后续涨价影响，首购的价格锁定终身
- **优惠码**：购买时用过优惠码的，续费会自动延续折扣，不用手动填

## 手动续费步骤（最常见的情况）

搬瓦工到期了怎么续费，标准流程就这几步：

**第一步**：登录搬瓦工后台客户中心（Client Area）

**第二步**：点击顶部菜单 → **Billing** → **My Invoices**，找到状态为 **Unpaid** 的账单

**第三步**：点进账单，核对金额和服务信息，确认没问题点 **Make Payment**

**第四步**：选择支付方式（支付宝/银联/信用卡/PayPal），完成付款

付款成功后，账单状态会从 Unpaid 变成 Paid，VPS 的服务周期自动延长。

## 没找到续费账单？先查这几个地方

登进后台没看到账单，不要慌，按顺序排查：

1. **确认当天是否是到期日**——账单不提前生成，到期当天才出。如果还没到那天，等就行了
2. **看看 Renewal Invoices 开关有没有关**——进 Services → My Services，找到你的 VPS，点小齿轮 → Manage renewal，确认开关是 **ON**。如果是 OFF，系统根本不会生成账单，到期就直接没了
3. **查邮件**——账单生成时搬瓦工会发一封标题含"Invoice"的邮件，记得看垃圾箱
4. **账单已经被余额自动扣了**——如果账户里有预充的余额，账单可能已经自动付掉了，去 My Invoices 里翻一下，看有没有 Paid 状态的账单

## 想省心？提前充值账户余额

这是用下来最稳的方式。

提前往账户里充一笔钱（Add Funds），额度够覆盖续费金额就行。账单一出来，系统自动扣，你连动手的机会都不需要。

进入路径：登录后台 → 右上角头像或 Billing → **Add Funds**

支持信用卡和 PayPal。需要注意的是，Add Funds 这个入口目前不支持支付宝直接充值——支付宝只能在购买或支付账单时使用，充余额这一步没法走支付宝通道。

想续费几年就充几年的钱，比如年付 $49.99 的套餐续 3 年，充 150 刀左右就够了，放在那里等系统自己扣。

## 换成年付，省下一截钱

如果你目前是月付或季付，可以在后台改成年付，算下来每个月的均摊成本低不少。

操作路径：Services → My Services → 找到 VPS → 小齿轮 → **Manage renewal** → 修改计费周期

几个要注意的点：

- 只能从短周期改到长周期（月付 → 季付 → 年付），不能反过来
- Renewal Invoices 必须是 ON 状态才能改
- 周期改了之后，价格会按新周期重新计算，可能失去老的价格锁定，改之前先确认一下新价格是否划算

## 续费之后，IP 会变吗？配置会变吗？

不会。续费只是延长服务周期，不改动任何东西——IP 地址不变、SSH 配置不变、系统里的文件一个没动，付款完成后直接继续用。

## 常见问题 Q&A

**Q：搬瓦工到期了当天没续费，数据丢了吗？**  
A：没有。到期当天账单生成，之后还有 7 天宽限期，VPS 照常跑着，数据完整。宽限期内付款，什么都不影响。

**Q：续费能不能用支付宝？**  
A：可以。在支付账单页面选择支付方式时，选 Alipay 就行。但要注意 Add Funds（充余额）这个入口目前不走支付宝，只能用信用卡或 PayPal。

**Q：首购没用优惠码，续费能补上吗？**  
A：不能。优惠码是购买时锁定的，续费延续首购时的折扣。没用过优惠码的，之后也无法补加。所以下次如果要买新套餐，记得提前查一下有没有当前有效的官方优惠码。

**Q：搬瓦工会在到期前提醒我吗？**  
A：账单在到期当天生成，生成后系统会发一封邮件通知。期间还会有 1-3 封追催邮件。建议把注册邮箱的垃圾箱也查一遍，以防漏掉。

**Q：不想续费了，怎么停？**  
A：进 Services → My Services，找到对应 VPS，点小齿轮 → Manage renewal，设置成 Do Not Renew 就行。到期后系统不会再生成账单，服务自动终止。
